# 周报模板与撰写规范（知识库文档 REPORT-004）

本模板用于「写周报」场景。Agent 生成本周周报时应遵循以下结构与措辞规范。

## 1. 标准结构

```
【本周周报】<姓名/团队> <起止日期>

一、本周完成
1. <事项>：<结果/指标>（<证据：PR 链接 / 数据 / 交付物>）
2. ...

二、进行中
1. <事项>：当前进度 <百分比>，预计 <完成时间>

三、风险与阻塞
1. <风险>：影响 <范围>，需要 <资源/决策>

四、下周计划
1. <事项>
2. ...
```

## 2. 撰写规范

- 每条不少于「做了什么 + 结果如何」两要素，禁止只写「参与了 X」。
- 量化优先：把「优化了性能」改写为「P99 从 800ms 降到 210ms」。
- 风险要写「需要谁做什么决定」，否则风险条目无意义。
- 单条不超过两行，全文控制在 400 字以内，方便主管 30 秒读完。

## 3. 常见反例

- 流水账：按时间罗列，看不出结果。
- 只有过程没有结论：全是「调研了」「对接了」。
- 隐藏风险：把阻塞写成「进展顺利」。
