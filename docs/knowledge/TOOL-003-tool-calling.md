# 工具调用与参数 Schema（知识库文档 TOOL-003）

## 1. 工具注册需要什么

一个可被 LLM 自主决策的工具至少要有四要素：

1. `name`：模型用来发起调用的标识，短、动词化、唯一。
2. `description`：模型判断「什么时候该用它」的唯一依据，要写清适用场景与边界。
3. `parameters`：JSON Schema，声明参数类型、必填项、枚举取值。
4. `execute`：真正的执行逻辑，必须可超时、可异常、可观测。

## 2. 参数校验

不要把参数校验完全交给模型。Runtime 应在调用前用 Schema 做一次结构校验，
校验失败要把「可读的错误说明」作为工具结果回灌给模型，让它自己修正参数重试。

## 3. 错误处理原则

工具执行失败不是致命错误，而是 observation：

- 未知工具名 -> 回灌 `unknown tool` 并附可用工具列表。
- 参数不合法 -> 回灌具体哪个字段错了。
- 执行超时 -> 回灌超时信息，模型可以换更小的请求重试。
- 执行抛异常 -> 回灌异常类型与消息（不要回灌完整堆栈，太占预算）。

## 4. 幂等性提醒

给模型开放写操作（如下单、删除）时必须考虑幂等与人工确认，
只读工具（计算、查询、检索）则相对安全。
